# سامانه مرکز آموزش علمی–کاربردی کمیته امداد امام خمینی (ره)

بازنویسی کامل سامانه وردپرسی `uastemdad.ir` با فناوری‌های مدرن، طراحی اختصاصی فارسی (RTL)، پنل مدیریت کامل و دستیار گفتگوی هوشمند.

## امکانات سامانه

### سایت عمومی
- طراحی اختصاصی «زمردی–طلایی» با فونت وزیرمتن، تم روشن/تاریک و کاملاً واکنش‌گرا (RTL)
- صفحه اصلی: اسلایدر، دسترسی سریع به سامانه‌ها (سما لایو، هم‌آوا، سجاد و…)، اخبار، اطلاعیه‌ها، آمار متحرک، رشته‌های تحصیلی، گالری و بخش ریاست مرکز
- آرشیو اخبار و اطلاعیه‌ها با جستجو، فیلتر دسته‌بندی و صفحه‌بندی
- صفحات دینامیک (درباره مرکز، تاریخچه، هیئت امنا، ریاست، همکاران، راهنمای طبقات)
- گالری تصاویر با لایت‌باکس، صفحه رشته‌های تحصیلی، فرم‌ها و آیین‌نامه‌ها
- فرم ارتباط با مرکز (ذخیره در دیتابیس و نمایش در پنل)
- تقویم شمسی در کل سامانه
- **دستیار هوشمند گفتگوی آنلاین**: پاسخ به پرسش‌ها بر اساس اخبار، اطلاعیه‌ها، رشته‌ها، سامانه‌ها و اطلاعات تماس — با ذخیره تاریخچه گفتگو و پاسخگویی به سه زبان

### چندزبانه و شخصی‌سازی
- **چند زبانه (فارسی / English / العربية)** با تغییر خودکار جهت صفحه (RTL/LTR)، ترجمه کامل رابط کاربری، پشتیبانی دستیار هوشمند از زبان انتخابی و فیلدهای ترجمه اخبار و صفحات (En/Ar) در پنل مدیریت
- **شخصی‌سازی نمایش**: تغییر فونت (وزیرمتن / سیستمی / تاهوما / نستعلیق‌مانند)، چهار اندازه متن، پنج رنگ پس‌زمینه (پیش‌فرض، کرم، نعنایی، آسمانی، شنی) — همه ذخیره خودکار در مرورگر
- **قابلیت‌های توان‌خواه (دسترسی‌پذیری)**: کنتراست بالا، بزرگ‌نمایی متن، زیرخط‌دار کردن لینک‌ها، کاهش حرکت و انیمیشن، فاصله سطر بیشتر، حالت شب — با دکمه شناور اختصاصی

### عضویت، خبرنامه و آمار
- **سامانه عضویت دانشجویان** (`/membership`): ثبت‌نام با مشخصات دانشجویی، ورود با شماره دانشجویی یا ایمیل، پنل اختصاصی عضو (ویرایش پروفایل، تغییر گذرواژه، تنظیم خبرنامه) و گردش تأیید مدیر
- **خبرنامه**: فرم عضویت در پاورقی و صفحه عضویت؛ مدیریت مشترکان در پنل
- **شمارنده و آمار بازدید**: بازدید امروز/کل و کاربران آنلاین در پاورقی؛ صفحه «آمار بازدید» در پنل مدیریت با نمودار روند ۱۴ روزه، صفحات پربازدید، مرورگرها، سیستم‌عامل‌ها، دستگاه‌ها و جدول آخرین بازدیدها

### پنل مدیریت (`/admin`)
- داشبورد آماری (اخبار، اطلاعیه‌ها، پیام‌ها، بازدیدها)
- مدیریت کامل اخبار و اطلاعیه‌ها با ویرایشگر متن غنی و تصویر شاخص (آپلود فایل) و فیلدهای ترجمه انگلیسی/عربی
- مدیریت صفحات، دسته‌بندی‌ها، اسلایدر، سامانه‌ها، رشته‌ها، فرم‌ها، گالری، هیئت امنا و همکاران، پیوندها، منوها و مشترکان خبرنامه
- **اعضای دانشجو**: تأیید/رد درخواست‌های عضویت، تغییر وضعیت و حذف
- **آمار بازدید**: تحلیل کامل ترافیک با نمودار
- صندوق پیام‌های دریافتی (خوانده‌شده/نشده، حذف)
- تنظیمات سامانه (نام، لوگو، آدرس، تلفن، ایمیل، آمار، پیام چت و…)
- مدیریت کاربران مدیر (افزودن، تغییر رمز، فعال/غیرفعال‌سازی، حذف)

## فناوری‌ها
- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Prisma ORM + SQLite
- احراز هویت اختصاصی (هش scrypt + کوکی امضاشده HMAC)
- هوش مصنوعی گفتگو با `z-ai-web-dev-sdk`
- آیکن‌ها: Lucide | تاریخ شمسی بدون وابستگی خارجی

## راه‌اندازی

### ویندوز با PowerShell (پورت 3003)
مستندات کامل و اسکریپت خودکار:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup.ps1          # نصب کامل + اجرا روی http://localhost:3003
```

راهنمای گام‌به‌گام: [`SETUP-POWERSHELL.md`](./SETUP-POWERSHELL.md)

### لینوکس / مک (یا محیط توسعه)

```bash
# ۱) نصب وابستگی‌ها
bun install   # یا npm install

# ۲) فایل محیطی
cp .env.example .env

# ۳) ساخت دیتابیس و داده اولیه (اخبار و محتوای واقعی سایت)
bun run db:push
bun run db:seed      # یا: npx tsx prisma/seed.ts

# ۴) اجرای محیط توسعه
bun run dev          # http://localhost:3000
bun run dev:3003     # یا روی پورت 3003

# ساخت نسخه پروداکشن
npm run build
PORT=3003 npm start
```

### ورود به پنل مدیریت
- آدرس: `/admin`
- نام کاربری: `admin`
- رمز عبور: `admin123`

### عضو نمونه
- آدرس: `/membership`
- شماره دانشجویی: `0921123456`
- رمز عبور: `member1234`

> پس از اولین ورود، از بخش «کاربران» رمز عبور را تغییر دهید.

## ساختار پروژه

```
prisma/schema.prisma        # مدل‌های دیتابیس
prisma/seed.ts              # داده اولیه (محتوای واقعی سامانه)
setup.ps1                   # نصب و اجرای خودکار در ویندوز (پورت 3003)
SETUP-POWERSHELL.md         # راهنمای PowerShell
src/lib/prefs.tsx           # موتور شخصی‌سازی و دسترسی‌پذیری
src/lib/i18n-dictionaries.ts# فرهنگ‌های چندزبانه (fa/en/ar)
src/lib/member-auth.ts      # احراز هویت اعضا
src/app/(site)/membership/  # سامانه عضویت دانشجویان
src/app/(site)/             # سایت عمومی
src/app/admin/(panel)/      # پنل مدیریت (اعضا، آمار بازدید و…)
src/app/api/                # APIها (چت هوشمند، عضویت، خبرنامه، آمار بازدید، CRUD ادمین)
src/components/site/        # کامپوننت‌های سایت
src/components/admin/       # کامپوننت‌های پنل
public/images/              # تصاویر واقعی منتقل‌شده از سامانه قبلی
public/fonts/               # فونت وزیرمتن
```

## نکات
- منوی سایت، اسلایدر و همه بخش‌ها از پنل مدیریت قابل ویرایش‌اند.
- برای افزودن فایل به «فرم‌ها و آیین‌نامه‌ها»، فایل را در همان بخش آپلود یا لینک مستقیم وارد کنید.
- تاریخ گفتگوهای دستیار هوشمند در جدول ChatMessage ذخیره می‌شود.
- زبان، فونت، اندازه متن و رنگ پس‌زمینه هر کاربر در مرورگر خودش (localStorage) ذخیره می‌شود؛ زبان فعال در کوکی `uast_locale` نیز برای رندر سمت سرور ثبت می‌گردد.
- آمار بازدید ربات‌ها و مسیرهای مدیریتی را شمارش نمی‌کند.
