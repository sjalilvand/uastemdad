# سامانه مرکز آموزش علمی–کاربردی کمیته امداد امام خمینی (ره)

بازنویسی کامل سامانه وردپرسی `uastemdad.ir` با فناوری‌های مدرن، طراحی اختصاصی فارسی (RTL)، پنل مدیریت کامل و دستیار گفتگوی هوشمند.

## امکانات سامانه

### سایت عمومی
- طراحی اختصاصی «زمردی–طلایی» با فونت وزیرمتن، تم روشن/تاریک و کاملاً واکنش‌گرا (RTL)
- صفحه اصلی: اسلایدر، دسترسی سریع به سامانه‌ها (سما لایو، هم‌آوا، سجاد و…)، اخبار، اطلاعیه‌ها، رویدادهای پیش رو، آمار متحرک، رشته‌های تحصیلی، گالری و بخش ریاست مرکز
- **نوار خبری متحرک (زیرنویس)**: اسکرول خودکار آخرین اطلاعیه‌ها زیر سربرگ با توقف هنگام هاور و قابلیت خاموش/روشن از تنظیمات
- آرشیو اخبار و اطلاعیه‌ها با جستجو، فیلتر دسته‌بندی و صفحه‌بندی
- صفحات دینامیک (درباره مرکز، تاریخچه، هیئت امنا، ریاست، همکاران، راهنمای طبقات)
- گالری تصاویر با لایت‌باکس، صفحه رشته‌های تحصیلی، فرم‌ها و آیین‌نامه‌ها
- **رسانه و ویدیوها** (`/media`): پخش ویدیوی آپارات، یوتیوب و فایل MP4 با پخش‌کننده تمام‌صفحه
- **پرسش‌های متداول** (`/faq`)، **تقویم رویدادها** (`/events`) و **اساتید و همکاران** (`/staff`)
- **نقشه مرکز** در صفحه تماس (OpenStreetMap با نشانگر و مسیریابی — مختصات قابل تنظیم از پنل)
- **خواندن متن (TTS)**: دکمه «گوش دادن به متن» در اخبار و صفحات — تبدیل متن به گفتار با صدای مرورگر
- فرم ارتباط با مرکز (ذخیره در دیتابیس و نمایش در پنل)
- تقویم شمسی در کل سامانه
- **دستیار هوشمند گفتگوی آنلاین**: پاسخ به پرسش‌ها بر اساس اخبار، اطلاعیه‌ها، رشته‌ها، سامانه‌ها، پرسش‌های متداول و اطلاعات تماس — با ذخیره تاریخچه، پاسخگویی به سه زبان و **موتور پاسخ محلی جایگزین** (اگر سرویس هوش مصنوعی در دسترس نباشد، پاسخ از داده‌های خود سامانه ساخته می‌شود و خطا نمایش داده نمی‌شود)

### PWA و اپ موبایل
- **اپ موبایل (PWA)**: نصب مستقیم از مرورگر روی اندروید، آیفون و دسکتاپ — مانیفست کامل، سرویس‌ورکر با کش آفلاین و صفحه آفلاین اختصاصی
- صفحه **نصب اپلیکیشن** (`/app`) با **کد QR سایت**، دکمه نصب و راهنمای گام‌به‌گام هر پلتفرم
- کارت تبلیغ نصب اپ در صفحه اصلی و اجرای تمام‌صفحه بدون نوار مرورگر پس از نصب

### چندزبانه و شخصی‌سازی
- **چند زبانه (فارسی / English / العربية)** با تغییر خودکار جهت صفحه (RTL/LTR)، ترجمه کامل رابط کاربری، پشتیبانی دستیار هوشمند از زبان انتخابی و فیلدهای ترجمه اخبار و صفحات (En/Ar) در پنل مدیریت
- **شخصی‌سازی نمایش**: تغییر فونت (وزیرمتن / سیستمی / تاهوما / نستعلیق‌مانند)، چهار اندازه متن، پنج رنگ پس‌زمینه (پیش‌فرض، کرم، نعنایی، آسمانی، شنی) — همه ذخیره خودکار در مرورگر
- **تم‌های رنگی**: ۷ تم (زمرد، نعنایی، اقیانوس، غروب، بنفش سلطنتی، سرخ گلگون و **رنگین‌کمان** با گرادیان متحرک) — اعمال فوری روی کل سایت و ذخیره خودکار
- **قابلیت‌های توان‌خواه (دسترسی‌پذیری)**: کنتراست بالا، بزرگ‌نمایی متن، زیرخط‌دار کردن لینک‌ها، کاهش حرکت و انیمیشن، فاصله سطر بیشتر، حالت شب — با دکمه شناور اختصاصی

### عضویت، خبرنامه و آمار
- **سامانه عضویت دانشجویان** (`/membership`): ثبت‌نام با مشخصات دانشجویی، ورود با شماره دانشجویی یا ایمیل، پنل اختصاصی عضو (ویرایش پروفایل، تغییر گذرواژه، تنظیم خبرنامه) و گردش تأیید مدیر
- **خبرنامه**: فرم عضویت در پاورقی و صفحه عضویت؛ مدیریت مشترکان در پنل
- **شمارنده و آمار بازدید**: بازدید امروز/کل و کاربران آنلاین در پاورقی؛ صفحه «آمار بازدید» در پنل مدیریت با کارت‌های آماری (امروز، هفته، ماه، یکتا، آنلاین، میانگین بازدید هر کاربر، **مدت کارکرد سرور**)، نمودار روند ۱۴ روزه، صفحات پربازدید، مرورگرها، سیستم‌عامل‌ها، دستگاه‌ها، **کشور و شهر بازدیدکنندگان** و جدول آخرین بازدیدها با **آدرس IP، موقعیت جغرافیایی، مرورگر، سیستم‌عامل، دستگاه و منبع ورود**

### پنل مدیریت (`/admin`)
- داشبورد آماری (اخبار، اطلاعیه‌ها، پیام‌ها، بازدیدها)
- مدیریت کامل اخبار و اطلاعیه‌ها با ویرایشگر متن غنی و تصویر شاخص (آپلود فایل) و فیلدهای ترجمه انگلیسی/عربی
- مدیریت صفحات، دسته‌بندی‌ها، اسلایدر، سامانه‌ها، رشته‌ها، فرم‌ها، گالری، هیئت امنا و همکاران، پیوندها، منوها و مشترکان خبرنامه
- **مدیریت ویدیوها و تیزرها** (آپارات/یوتیوب/MP4)، **پرسش‌های متداول** و **تقویم رویدادها**
- **اعضای دانشجو**: تأیید/رد درخواست‌های عضویت، تغییر وضعیت و حذف
- **آمار بازدید**: تحلیل کامل ترافیک با نمودار و مشخصات بازدیدکنندگان (IP، کشور، شهر)
- صندوق پیام‌های دریافتی (خوانده‌شده/نشده، حذف)
- تنظیمات سامانه (نام، لوگو، آدرس، تلفن، ایمیل، مختصات نقشه، نوار خبری متحرک، آمار، پیام چت و…)
- مدیریت کاربران مدیر (افزودن، تغییر رمز، فعال/غیرفعال‌سازی، حذف)
- **صفحهٔ «بات بله»**: وضعیت اتصال، مدیران متصل، ری‌استارت/توقف polling و گزارش فعالیت

### بات بله (`@Universityemdad_bot`)
مدیران می‌توانند بدون ورود به پنل، از پیام‌رسان بله خبر و اطلاعیه را همراه با عکس منتشر کنند:

- آدرس بات: [ble.ir/Universityemdad_bot](https://ble.ir/Universityemdad_bot)
- ورود امن: ارسال `/start` ← نام کاربری و گذرواژهٔ پنل ← اتصال یک‌بارهٔ حساب (پیام گذرواژه خودکار حذف می‌شود)
- ویزارد گرافیکی ۵ مرحله‌ای با دکمه‌های شیشه‌ای: عنوان ← خلاصه ← متن کامل ← **ارسال عکس‌ها (تا ۱۰ عکس، اولین عکس تصویر شاخص)** ← دسته‌بندی
- پیش‌نمایش آلبوم عکس‌ها قبل از انتشار؛ دکمه‌های «انتشار در سایت»، «ذخیرهٔ پیش‌نویس»، «نوشتن از نو»
- فهرست اخبار با لینک مستقیم و حذف از داخل بات؛ وضعیت بات و راهنمای داخلی
- لینک دکمه‌های وب: مشاهدهٔ خبر در سایت بلافاصله پس از انتشار

فعال‌سازی: متغیر `BALE_BOT_TOKEN` در `.env` (در deploy.ps1 به‌صورت خودکار تنظیم می‌شود) و `BALE_BOT_ENABLED=true`. بات به‌صورت long-polling داخل خود سرور Next اجرا می‌شود و به پورت یا تنظیمات اضافه نیاز ندارد.

## فناوری‌ها
- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Prisma ORM + SQLite
- احراز هویت اختصاصی (هش scrypt + کوکی امضاشده HMAC)
- هوش مصنوعی گفتگو با `z-ai-web-dev-sdk`
- آیکن‌ها: Lucide | تاریخ شمسی بدون وابستگی خارجی

## راه‌اندازی

### ویندوز با PowerShell (پورت 3003)
مستندات کامل و اسکریپت خودکار:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup.ps1          # نصب کامل + اجرا روی http://localhost:3003
```

راهنمای گام‌به‌گام: [`SETUP-POWERSHELL.md`](./SETUP-POWERSHELL.md)

### لینوکس / مک (یا محیط توسعه)

```bash
# ۱) نصب وابستگی‌ها
bun install   # یا npm install

# ۲) فایل محیطی
cp .env.example .env

# ۳) ساخت دیتابیس و داده اولیه (اخبار و محتوای واقعی سایت)
bun run db:push
bun run db:seed      # یا: npx tsx prisma/seed.ts

# ۴) اجرای محیط توسعه
bun run dev          # http://localhost:3000
bun run dev:3003     # یا روی پورت 3003

# ساخت نسخه پروداکشن
npm run build
PORT=3003 npm start
```

### ورود به پنل مدیریت
- آدرس: `/admin`
- نام کاربری: `admin`
- رمز عبور: `admin123`

### عضو نمونه
- آدرس: `/membership`
- شماره دانشجویی: `0921123456`
- رمز عبور: `member1234`

> پس از اولین ورود، از بخش «کاربران» رمز عبور را تغییر دهید.

## پایش و عملیات (سرور ویندوز)

سامانه سه لایهٔ پایش دارد تا دان‌شدن هرگز بی‌سروصدا نباشد: نقطهٔ سلامت `/api/health`، مانیتور داخلی (گزارش «بالا آمد + مدت قطعی» به مدیرانِ بات بله) و پایشگر بیرونی هر ۱ دقیقه با راه‌اندازی مجدد خودکار تا ۳ بار.

```powershell
# نصب پایش روی سرور (یک‌بار، با دسترسی Administrator):
powershell -ExecutionPolicy Bypass -File C:\uastemdad\app\install-monitor.ps1
# آزمایش:
powershell -ExecutionPolicy Bypass -File C:\uastemdad\app\scripts\monitor-app.ps1 -Test
```

- چک‌لیست عیب‌یابی: [`docs/CHECKLIST.md`](./docs/CHECKLIST.md)
- راهنمای کامل عملیات و نگهداری: [`docs/RUNBOOK.md`](./docs/RUNBOOK.md)
- پیام‌های هشدار پایشگر (دان ماندن/HTTPS/دیسک) با تنظیم `MONITOR_CHAT_ID` فعال می‌شوند: در بات `/status` بزنید و شناسه را با `set-monitor-chat.ps1 -ChatId <شناسه>` ثبت کنید.

## نکات
- منوی سایت، اسلایدر و همه بخش‌ها از پنل مدیریت قابل ویرایش‌اند.
- برای افزودن فایل به «فرم‌ها و آیین‌نامه‌ها»، فایل را در همان بخش آپلود یا لینک مستقیم وارد کنید.
- تاریخ گفتگوهای دستیار هوشمند در جدول ChatMessage ذخیره می‌شود؛ اگر سرویس هوش مصنوعی قطع باشد، دستیار به‌صورت خودکار از موتور محلی (تطبیق کلیدواژه روی داده‌های سایت) پاسخ می‌دهد.
- زبان، فونت، اندازه متن، تم رنگی و رنگ پس‌زمینه هر کاربر در مرورگر خودش (localStorage) ذخیره می‌شود؛ زبان فعال در کوکی `uast_locale` نیز برای رندر سمت سرور ثبت می‌گردد.
- آمار بازدید ربات‌ها و مسیرهای مدیریتی را شمارش نمی‌کند؛ موقعیت جغرافیایی (کشور/شهر) از IP با سرویس رایگان ip-api و با کش داخلی ثبت می‌شود (برای IPهای محلی «شبکه محلی» ثبت می‌گردد).
- آیکن‌های PWA از لوگوی سایت ساخته می‌شوند (اسکریپت `scripts/make-icons.js`). برای تغییر مختصات نقشه، مقدارهای `mapLat` و `mapLng` را در تنظیمات پنل بدهید.
