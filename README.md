# سامانه مرکز آموزش علمی–کاربردی کمیته امداد امام خمینی (ره)

بازنویسی کامل سامانه وردپرسی `uastemdad.ir` با فناوری‌های مدرن، طراحی اختصاصی فارسی (RTL)، پنل مدیریت کامل و دستیار گفتگوی هوشمند.

## امکانات سامانه

### سایت عمومی
- طراحی اختصاصی «زمردی–طلایی» با فونت وزیرمتن، تم روشن/تاریک و کاملاً واکنش‌گرا (RTL)
- صفحه اصلی: اسلایدر، دسترسی سریع به سامانه‌ها (سما لایو، هم‌آوا، سجاد و…)، اخبار، اطلاعیه‌ها، آمار متحرک، رشته‌های تحصیلی، گالری و بخش ریاست مرکز
- آرشیو اخبار و اطلاعیه‌ها با جستجو، فیلتر دسته‌بندی و صفحه‌بندی
- صفحات دینامیک (درباره مرکز، تاریخچه، هیئت امنا، ریاست، همکاران، راهنمای طبقات)
- گالری تصاویر با لایت‌باکس، صفحه رشته‌های تحصیلی، فرم‌ها و آیین‌نامه‌ها
- فرم ارتباط با مرکز (ذخیره در دیتابیس و نمایش در پنل)
- تقویم شمسی در کل سامانه
- **دستیار هوشمند گفتگوی آنلاین**: پاسخ به پرسش‌ها بر اساس اخبار، اطلاعیه‌ها، رشته‌ها، سامانه‌ها و اطلاعات تماس — با ذخیره تاریخچه گفتگو

### پنل مدیریت (`/admin`)
- داشبورد آماری (اخبار، اطلاعیه‌ها، پیام‌ها، بازدیدها)
- مدیریت کامل اخبار و اطلاعیه‌ها با ویرایشگر متن غنی و تصویر شاخص (آپلود فایل)
- مدیریت صفحات، دسته‌بندی‌ها، اسلایدر، سامانه‌ها، رشته‌ها، فرم‌ها، گالری، هیئت امنا و همکاران، پیوندها و **منوهای سایت**
- صندوق پیام‌های دریافتی (خوانده‌شده/نشده، حذف)
- تنظیمات سامانه (نام، لوگو، آدرس، تلفن، ایمیل، آمار، پیام چت و…)
- مدیریت کاربران مدیر (افزودن، تغییر رمز، فعال/غیرفعال‌سازی، حذف)

## فناوری‌ها
- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Prisma ORM + SQLite
- احراز هویت اختصاصی (هش scrypt + کوکی امضاشده HMAC)
- هوش مصنوعی گفتگو با `z-ai-web-dev-sdk`
- آیکن‌ها: Lucide | تاریخ شمسی بدون وابستگی خارجی

## راه‌اندازی

```bash
# ۱) نصب وابستگی‌ها
bun install   # یا npm install

# ۲) فایل محیطی
echo 'DATABASE_URL="file:./custom.db"' > .env
# برای دستیار هوشمند نیازی به کلید جداگانه نیست؛ در محیط سازگار z-ai به‌صورت خودکار فعال می‌شود

# ۳) ساخت دیتابیس و داده اولیه (اخبار و محتوای واقعی سایت)
bun run db:push
bun prisma/seed.ts

# ۴) اجرای محیط توسعه
bun run dev        # http://localhost:3000

# ساخت نسخه پروداکشن
bun run build && bun run start
```

### ورود به پنل مدیریت
- آدرس: `/admin`
- نام کاربری: `admin`
- رمز عبور: `admin123`

> پس از اولین ورود، از بخش «کاربران» رمز عبور را تغییر دهید.

## ساختار پروژه

```
prisma/schema.prisma        # مدل‌های دیتابیس
prisma/seed.ts              # داده اولیه (محتوای واقعی سامانه)
src/lib/                    # احراز هویت، تاریخ شمسی، تنظیمات، پیکربندی ادمین
src/app/(site)/             # سایت عمومی
src/app/admin/              # پنل مدیریت
src/app/api/                # APIها (چت هوشمند، تماس، CRUD ادمین، آپلود)
src/components/site/        # کامپوننت‌های سایت
src/components/admin/       # کامپوننت‌های پنل (ویرایشگر، آپلود، CRUD عمومی)
public/images/              # تصاویر واقعی منتقل‌شده از سامانه قبلی
public/fonts/               # فونت وزیرمتن
```

## نکات
- منوی سایت، اسلایدر و همه بخش‌ها از پنل مدیریت قابل ویرایش‌اند.
- برای افزودن فایل به «فرم‌ها و آیین‌نامه‌ها»، فایل را در همان بخش آپلود یا لینک مستقیم وارد کنید.
- تاریخ گفتگوهای دستیار هوشمند در جدول ChatMessage ذخیره می‌شود.
